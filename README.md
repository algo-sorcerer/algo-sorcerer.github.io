## 🔬 The 6 Interactive Algorithm Laboratories
Every simulation produces a deterministic state change with real-time computational readouts:
1. 🌀 **Lab A: Recursion and Call Stacks**: Expanding/unwinding stack frames, push/pop operations, base case boundary activation ($O(N)$ time, $O(N)$ space).
2. 🎯 **Lab B: Binary Search & Pruning**: Target key selection (7, 23, 42, 88), highlighted search intervals, animated midpoint checks, dimmed pruned intervals ($O(\log N)$ time, $O(1)$ space).
3. 🕸️ **Lab C: Graph Theory & Distributed DAGs**: Interdependent microservices, request impulse propagation on click, topological dependency traversal ($O(V + E)$ time, $O(V)$ space).
4. 🧹 **Lab D: Garbage Collection & Heap Optimization**: GC root pointers, live reachable references, orphaned dead blocks, manual GC trigger button with live reclaimed byte counters.
5. 📿 **Lab E: Dynamic Programming & Memoization**: Mode toggle comparing Naive Recursion ($O(2^N)$ call explosion) vs Memoized Lookup Table ($O(N)$ cache hits).
6. ⚖️ **Lab F: Sorting & Shannon Entropy**: QuickSort and MergeSort partitioning with real-time Shannon Entropy readout $H(X) = -\sum P(x) \log_2 P(x)$ visibly reducing disorder to equilibrium.
